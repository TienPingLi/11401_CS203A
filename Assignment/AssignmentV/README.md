
# 作業報告：樹狀資料結構 (Tree Data Structures)

## 1. 專案簡介

本報告為 **Data Structures (CSE CS203A)** 課程的第五次作業 。目標在於深入探討「樹」這一資料結構，從基礎的「一般樹」延伸至各類進階變體（如 AVL Tree、Red-Black Tree 等），並理解其在現實世界中的應用 。

## 2. 作業目標

* 
**定義學習**：清晰定義 8 種樹狀結構 。


* 
**層級分析**：建立樹狀家族層級圖，解釋各變體間的限制與轉換關係 。


* 
**實作模擬**：使用指定的 20 個整數序列建構各類樹，並進行視覺化展示 。


* 
**應用分析**：為每種樹找到適合的實際應用場景 。


* 
**AI 協作**：練習將 AI 作為學習夥伴，並完整記錄互動過程 。



## 3. 輸入數據

本作業中所有樹的建構皆使用以下 20 個整數（依序輸入）：

> **37, 142, 5, 89, 63, 117, 24, 176, 58, 133, 92, 11, 151, 72, 39, 184, 7, 101, 54, 160**

## 4. 報告架構 (Student Worksheet 內容)

### 第一部分：定義 (Definitions)

包含以下結構的自主定義 ：

1. **General Tree** (一般樹)
2. **Binary Tree** (二元樹)
3. **Complete Binary Tree** (完全二元樹)
4. **Binary Search Tree (BST)** (二元搜尋樹)
5. **AVL Tree** (AVL 樹)
6. **Red-Black Tree** (紅黑樹)
7. **Max Heap** (最大堆積)
8. **Min Heap** (最小堆積)

### 第二部分：層級與轉換 (Hierarchy & Transformations)

* 
**轉換圖表**：展示從一般樹進化到 specialized forms 的路徑 。


* 
**限制說明**：詳細填寫每種轉換所增加的性質（例如：BST 加入了「左小右大」的限制）。



### 第三部分：樹的建構與視覺化 (Constructions & Visualizations)

針對每一種樹提供 ：

* 使用的視覺化工具名稱或 URL 。


* 建構過程描述（如：插入順序、平衡旋轉過程）。


* 建構完成後的視覺化截圖 。



### 第四部分：應用實例 (Application Examples)

分析每種樹結構最適合的應用場景（如：優先權佇列、資料庫索引、記憶體分配等）及其適配原因 。
